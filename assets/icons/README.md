# Iconos

- Iconos de la interfaz: [Lucide](https://lucide.dev) 1.77.0 (`lucide-static`),
  licencia ISC (ver `LICENSE-lucide.txt`). Trazo ajustado a 1,75; se tiñen con el
  color del tema en tiempo de ejecución (`currentColor`).
  Correspondencia: sidebar=panel-left, open=folder-open, save, undo=undo-2,
  redo=redo-2, select=mouse-pointer-2, edit-text=square-pen, add-text=type,
  image=image-plus, rotate-left=rotate-ccw, rotate-right=rotate-cw,
  trash=trash-2, zoom-in, zoom-out, fit-width=move-horizontal,
  drop-file=file-up (trazo 1,5), file-open=file-text (trazo 1,5), sign=signature.
- Icono de la aplicación (`app.*`, `app-small.png`): propio, generado con
  `tools/make_icon.py` con la tipografía Inter Black (SIL OFL, en `tools/fonts/`,
  solo para generarlo). Desde 32 px se lee «xpdf»; a 24 px o menos, solo la «x».
